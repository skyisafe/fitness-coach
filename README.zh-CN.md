# fitness-coach · 综合运动锻炼教练

[English](README.md) | **简体中文**

> MIT License ｜ 无运行时依赖 ｜ 当前版本见 `SKILL.md`

为 AI Agent 提供综合运动锻炼教练能力：基于身体数据分析（BMI、基础代谢、每日总消耗），生成科学、可执行、带进阶机制的周期化运动计划——健身房器械力量、居家无器材自重、跑步、骑行、游泳、徒步同等覆盖，并精通营养学与体重控制。

> 说明：skill 的指令与参考文件为中文，教练以中文回复；本仓库同时提供 [英文 README](README.md) 作为默认首页，中文版用于中文用户阅读。

## 概述

- **是什么**：一个综合运动锻炼教练 skill——力量、自重、耐力（跑步/游泳/徒步/骑行）与营养体重管理全覆盖，健身房、居家无器械、户外同等对待。
- **适合谁**：想减脂/增重/塑形/提升体能的人；有体脂秤或 InBody 数据、需要解读的人；需要「每周照着练」的现成计划与动态调整的人。
- **不适合谁**：竞技备赛、运动损伤康复处方、疾病医疗营养治疗——这些超出教练边界，请找专业人士。
- **类型**：知识 + 工作流型 skill（无脚本）；主文件精简，领域知识按需从 `references/` 加载，数字口径统一维护在 `references/evidence.md`，避免多处漂移。

## 快速开始

1. 直接说诉求并附身体数据：「我 30 岁 175cm 78kg 想减脂，健身房每周 3 练，做个四周计划」
2. 数据不全时会**分步**补问（基础信息 → 训练背景 → 时间投入 → 伤病与身体数据），每步一屏、点选即答；**六项基础信息（性别/年龄/身高/体重/目标/运动状态）已齐则直接出计划**，开头用一行「本次假设」声明未采集项，纠正后立即重排；不想答可以说「按默认来」，教练按估算兜底。计划周期默认一周，需要更长（两周、四周、八周）请在消息里说明。
3. 要饮食或补给时单独提出：「帮我安排减脂期三餐」「蛋白粉和肌酸怎么选」「空腹有氧好不好」；不问不主动展开。
4. 练完带着反馈回来（重量组次、配速心率、体重腰围），直接说「第二周了，深蹲 40kg 轻松做满 12 次」即可进入动态调整。

## 触发方式

- 自动触发：消息中出现健身、锻炼、减脂、减重、减肥、增肌、塑形、体能、体脂、体脂秤、腹肌、臀腿、瘦肚瘦腰、哑铃、弹力带、无器械、出差、宿舍、三餐食谱、蛋白粉、肌酸、跑步、游泳、徒步、训练计划等关键词时自动加载。
- 强制触发：`/fitness-coach 你的问题`
- 完整触发词以 `SKILL.md` frontmatter 的 `description` / `triggers` 为准，不在此重复维护。

## 核心能力

- **算**：BMI（中国标准）、腰围、体脂参考、BMR（Mifflin-St Jeor）、TDEE、热量与蛋白质目标，全部标注估算与证据强度。
- **读**：体脂秤 / InBody / 体检报告的体成分页（支持图片转写），转成 7 项标准格式并联动解读。
- **自检**：交付前过 5 项闭环——缺口 ↔ 速度 ↔ 时间线、动作组次与起始重量、有氧四要素、蛋白克数、八段结构；算术对不上的计划不出稿。
- **排**：按每周天数选分化（2~6 天）、按周期输出逐日课表（默认一周，可延长到四周/八周滚动），训练日默认周一至周五。
- **给数字**：器械动作按体重比例给起始重量（单边/总重）、跑步机与有氧器械给坡度/配速/踏频/心率区间、自重动作给变式与次数区间。
- **教技术**：热身、8 个核心动作技术要点、呼吸与 Valsalva、护具、DOMS 与损伤分流（technique.md）。
- **顾边界**：孕期产后、月经周期与围绝经、65+、未成年、已控制高血压/2 型糖尿病、进食障碍与 RED-S 的剂量、禁忌与转介（populations.md）。
- **调**：按回访反馈做 L1 参数 / L2 结构 / L3 目标三级调整，输出「本周调整」对比表 + 全量周课表。
- **带模板**：四套现成排期（薄肌、瘦胖子、三分化、无器材），代入个人数据后直接可用。
- **可审计**：数字出处、证据强度与低能量膳食下限等口径集中在 evidence.md。

## 边界与注意事项

- 计划与饮食建议不构成医疗建议。出现以下情况会先建议就医：血压 ≥180/110、不明原因晕厥/胸痛、近期心肌炎、妊娠并发症、未控制的增殖性视网膜病变、进食障碍或 BMI <18.5 伴体重快速下降、65 岁以上未评估的骨质疏松、未成年人减重需求。
- 体脂率在无实测时为公式估算，精度低于 DEXA、InBody；体脂秤的肌肉率、内脏脂肪等级、骨量是厂商模型，不能当医学标准。
- 不覆盖：竞技体育备赛、运动损伤康复处方、疾病医疗营养治疗。
- 数字口径与出处统一维护在 `references/evidence.md`；发现冲突以该文件为准并回改，不要在多个文件重复维护同一数值。
- 当前版本见 `SKILL.md` frontmatter；历史变更见 `CHANGELOG.md`；设计取舍见 `DESIGN.md`。
