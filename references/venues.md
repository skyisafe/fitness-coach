# 运动状态与训练动作库

按用户**运动状态**路由，共两大类：**健身房健身**（器械 / 自由重量 / 跑步机）与**非健身房健身**——室内（无器材、家庭小器材、有氧器械）与室外运动（跑步、骑行、游泳、徒步）。原则：优先选用户能坚持、动作能学会的方案；每个动作给一个降阶替代。分化模板由 `SKILL.md` 第 5 步统一处理，本节只列动作库与执行参数；动作技术要点见 `technique.md`。

---

## 健身房健身

器械、自由重量与跑步机齐全的完整训练场景。

### 健身房（器械与自由重量）

**器材受限时**：用户给出实际器材清单时，严格按清单重构动作库——清单里没有的部位（常见缺口：背、腿器械）用自重动作替代，并**明示缺口与升级路径**（如「练满 4 周后建议解锁腿举/深蹲架」「有单杠或弹力带告诉我即可升级背部动作」）；不要假设健身房有清单外的器材。

**起始重量参考（新手~初级，按体重比例 BW 折算，第一次训练即校准）**——计划输出时每个力量动作都必须带上推荐起始重量：

| 动作 | 起始重量参考 | 备注 |
|---|---|---|
| 杠铃深蹲 | 先空杆 20kg 学动作 → 工作重量 0.5~0.75×BW | 总重（含杆） |
| 杠铃硬拉 | 0.6~0.8×BW | 总重 |
| 哑铃 RDL | 单边 0.15~0.2×BW | 单边 |
| 腿举 | 1~1.5×BW | 总重（含踏板） |
| 腿弯举 | 0.35~0.5×BW | 总重 |
| 平板/上斜哑铃卧推 | 单边 0.15~0.2×BW | 单边 |
| 杠铃卧推 | 先空杆学动作 → 0.4~0.5×BW | 总重 |
| 哑铃飞鸟 | 单边 0.08~0.12×BW | 单边 |
| 坐姿推胸机 | ≈0.4×BW | 悍马/分动推胸 ≈单边 0.1×BW |
| 蝴蝶机夹胸 | 0.15~0.25×BW | 总重 |
| 哑铃肩推 | 单边 0.1~0.15×BW | 单边 |
| 侧平举 | 单边 0.05~0.08×BW | 单边 |
| 高位下拉 | 0.4~0.5×BW | 总重 |
| 坐姿划船 | 0.4~0.5×BW | 总重 |
| 绳索下压 / 弯举 | 0.15~0.25×BW | 总重 |
| 后肩/反打类 | ≈0.1×BW | 总重 |
| 双杠臂屈伸 / 引体向上 | 自重起步 | 做不满 8 次用辅助机，助力 20~30kg（助力越少越强） |

女性起步 = 上表 ×0.5~0.7（上肢动作取低限、下肢取 0.6~0.7）。家庭健身的哑铃动作按同表折算。

**自校准法定实际重量（写进计划的执行规则）**：前两周宁轻勿重；能标准完成 12 次且还剩 3~4 次余力 = 合适（RPE 7）；全组轻松打到 12 次 → 下次哑铃 +2kg、杠铃/器械 +2.5~5kg，次数回落到 8 重新爬（即 `programs.md` §渐进超负荷的「双重渐进法」）；做不到 8 次或动作变形 → 减一档。配重牌各品牌规格不同，参考值只是起点，第一次训练即校准并记入训练日志。

固定器械动作库（按模式）：

| 模式 | 首选 | 替代 |
|---|---|---|
| 蹲 | 杠铃深蹲、腿举 | 哈克深蹲、史密斯深蹲 |
| 髋铰链 | 杠铃硬拉/罗马尼亚硬拉 | 臀推、俯卧弯腿 |
| 水平推 | 平板卧推、哑铃卧推 | 坐姿推胸机 |
| 上斜推 | 上斜哑铃卧推 | 上斜史密斯 |
| 垂直推 | 站姿/坐姿杠铃或哑铃肩推 | 器械肩推 |
| 水平拉 | 坐姿划船、哑铃划船 | T 杠划船 |
| 垂直拉 | 高位下拉 | 弹力带/辅助引体 → 引体向上 |
| 核心 | 绳索卷腹、悬垂举腿 | 帕洛夫 Press |

参数：复合 3~4×6~12；孤立 2~3×10~15；组间休息复合 2~3min、孤立 60~90s；每次训练 45~75min 内完成。

有氧器械排序（关节友好度）：划船机 ≥ 椭圆机 > 单车 > 跑步机坡走（坡度 8~12%、速度 5~6km/h，对膝盖比平跑友好）> 平地跑。跑步机参数详见 §跑步机；其他器械见 §有氧器械。

新手第一次去健身房：先用固定器械学轨迹，第 2~4 周再过渡到自由重量；深蹲硬拉建议先空杆/轻重量练动作，技术要点见 `technique.md` §二、8 个核心动作技术要点。

### 跑步机（健身房 / 家用）

有氧日排在跑步机上时按本节执行（健身房与家用跑步机通用，家用属非健身房·室内的有氧主力）。核心原则：**坡度与配速为心率服务**——先定心率区间（最大心率优先用 Tanaka：208−0.7×年龄；中等强度 = 64%~76% HRmax 或 40%~59% HRR，能完整说句子），再用下表定起步值，跑完按心率校准。

**坡度默认**：慢跑 1%（补偿跑步机无风阻，能耗对齐户外跑）；坡走 8~12%（对膝盖比平跑友好，大体重/膝盖不适首选）。

**起步配速参考**（体重越大、经验越少取下限）：

| 水平 | 慢跑 | 快走 |
|---|---|---|
| 从零开始 / 大体重 | 6.0~7.0 km/h（走跑结合） | 5.0~5.5 km/h |
| 新手~练 3 个月 | 7.0~8.0 km/h | 5.5~6.5 km/h |
| 能连续跑 20min+ | 8.0~9.5 km/h | 6.0~6.5 km/h |

**标准课结构（20~40min）**：

- 热身 5min：速度 5.0 → 6.0 → 6.5 km/h 递进，坡度 0 → 1%
- 主项三选一：
  - 走跑结合（新手前 2 周）：慢跑 3min @ 1%、7.5 km/h + 快走 2min @ 6.0~6.5 km/h，循环 5~6 组
  - 连续慢跑（第 3 周起）：20~35min @ 1%，配速取「还能完整说话」的上限
  - 坡走平替（大体重/膝盖不适/不想跑）：10~12% + 5.0~5.5 km/h × 30~40min
- 冷身 5min：降回 5.0 → 4.0 km/h，坡度归 0

**课中微调**（每 5 分钟核对心率/谈话测试）：心率低于区间下限 → 速度 +0.5 km/h 或坡度 +1%；超过区间上限或说不出完整句子 → 速度 −0.5 km/h。

**间歇日**（每周 ≤1 次，与力量日错开）：30s 冲刺 @「当前慢跑配速 ×1.2~1.3」或「能维持 30 秒的最快速度」（新手通常 7~9 km/h，不直接上 10~12）+ 90s 慢走 @ 5.0~5.5 km/h（心率回落后再冲下一组）×6~8。

**进阶与安全**：先加时长（每周 +5~10min）再提配速（每周 +0.5 km/h）；「周跑量 ≤10%」是经验法则、无 RCT 证明防伤（新手跑者 10% vs 24% 损伤率无差异），更可靠的是总负荷渐进 + 疼痛/睡眠监控 + 每 3~4 周减量；上下机先停带再跨，扶手只在失衡时碰；计划输出必须写明本次课的坡度、配速与心率区间。

## 非健身房健身 · 室内

宿舍、出差、居家场景：无器材走 §无器材健身，有哑铃/弹力带等小器材走 §家庭健身；家用跑步机有氧按 §跑步机执行；单车/椭圆机/划船机/跳绳走 §有氧器械。

### 无器材健身（纯自重）

适用：完全无器械、出差、宿舍。负重进阶手段：背包装书/水瓶、放慢离心（4 秒下放）、缩短休息、单侧化。动作技术要点见 `technique.md`。

- 水平推：俯卧撑（标准/钻石/下斜脚垫高）｜降阶：上斜推墙 → 跪姿俯卧撑
- 垂直推：派克俯卧撑（倒立肩推降阶）｜降阶：手撑椅面肩推
- 水平拉：毛巾门缝划船、桌下划船（确保桌子稳固压稳）｜降阶：仰卧划船找低单杠/稳固桌沿
- 垂直拉：引体向上（小区单杠）｜降阶：弹力带辅助引体 → 离心引体（跳上去 5 秒慢放）
- 蹲：自重深蹲 → 分腿蹲 → 保加利亚分腿蹲（脚垫椅子）｜降阶：箱式深蹲（坐椅子）
- 髋铰链：单腿罗马尼亚硬拉（自重）、俯卧挺身（背起）｜降阶：屈膝幅度减小的 Good Morning
- 臀：臀桥 → 单腿臀桥
- 核心：平板支撑、侧支撑、死虫式、鸟狗式、卷腹、登山跑
- 有氧/全身：开合跳、高抬腿、波比跳｜降阶：去俯卧撑的原地起跳波比
- HIIT 模板：Tabata（20s 全力 + 10s 休息 ×8 动作轮换，共 4 分钟）或 30s 动 + 30s 休 ×5 动作循环

示例 30 分钟全身课（无器材）：

| 动作 | 组×次 | 休息 |
|---|---|---|
| 深蹲 | 3×15~20 | 60s |
| 跪姿/标准俯卧撑 | 3×8~15 | 60s |
| 保加利亚分腿蹲 | 3×10~12/侧 | 60s |
| 毛巾划船 | 3×12~15 | 60s |
| 平板支撑 | 3×30~45s | 45s |
| 波比跳（收尾） | 2×10~15 | 60s |

### 家庭健身（哑铃/弹力带/可调凳等小器材）

动作选择优先级：哑铃 > 弹力带 > 自重。一对可调哑铃即可覆盖全身。

- 推：哑铃卧推、上斜哑铃卧推（靠背垫高）、坐姿哑铃肩推、哑铃飞鸟｜降阶：减轻重量、地板卧推
- 拉：单臂哑铃划船（扶椅）、俯身双臂划船、弹力带面拉、直臂下压｜降阶：减轻、减少幅度
- 腿：高脚杯深蹲、哑铃罗马尼亚硬拉（RDL）、箭步蹲、保加利亚分腿蹲、哑铃提踵｜降阶：徒手版
- 全身：哑铃摇摆（Swing，需髋发力教学）、农夫行走（双手提哑铃走 30~40m）
- 弹力带补充：高位下拉（固定门上方）、坐姿划船、侧平举、弹力带深蹲
- 有氧：跳绳（30~60s × 8~10 组，见 §有氧器械）、家庭 HIIT、垫上核心

空间/噪音受限（公寓、楼上楼下休息）：避开跳绳与跳跃，用坡度俯卧撑、慢速深蹲、静力支撑类替代；有氧改低冲击开合（无跳开合跳）、登山跑。

### 有氧器械（单车 / 椭圆机 / 划船机 / 跳绳）

**通用**：中等强度 = 能说话但不能唱歌，或 64%~76% HRmax（约 10 分制 RPE 5~6，即 Borg 11~13 量表）；从下表起步，逐步累积到每周 150~300min（WHO 2020）；单次 20~45min，频次按目标见 `SKILL.md` 第 5 步（减脂 2~3 / 增肌重组 1~2 次/周）。

| 器械 | 初学者起始参数 | 中等强度目标 | RPE（10 分制） |
|---|---|---|---|
| 功率单车 | 阻力小~中，踏频 60~80 rpm | 60~80 rpm，20~45min | 5~6 |
| 椭圆机 | 低~中阻力，步频 100~140 步/分 | 20~40min，阻力中 | 5~6 |
| 划船机 | 阻力档 3~5，20~22 桨/分（spm） | 22~26 spm，500m 配速 2:20~2:50 | 6~7 |
| 跳绳 | 30~60s × 8~10 组，组间 30~60s | 连续 2~3min × 5 组 | 6~7 |

- 功率单车踏频低于 50 rpm 膝关节负荷增加，高于 90 rpm 对初学者心肺要求偏高；用阻力保持 60~80 rpm。
- 划船机动作顺序：腿 → 髋 → 臂，回程相反；腰背保持中立，别用腰甩。
- 跳绳落地前脚掌缓冲、膝微屈；膝踝不适、大体重或楼上楼下改低冲击有氧。

## 非健身房健身 · 室外运动

户外有氧与器械角：跑步、骑行、游泳、徒步按对应小节执行。

### 户外与跑步

跑步入门（从零开始）：

- 走跑结合：慢跑 1min + 快走 2min ×8~10 组，隔天跑；加量用「每周 +5~10min 或总时长 +10%（取小者）」，零基础从每次 +1~2min 起（在跑步机上执行时，坡度与配速起步值见 §跑步机）
- 4~6 周后过渡到连续慢跑 20~30min；配速以「还能说话」为准（谈话测试）
- 心率区间：最大心率优先 Tanaka 208−0.7×年龄（220−年龄仅粗略、个体误差 ±10~12）；中等强度 64%~76% HRmax 或 40%~59% HRR
- HIIT 变式：30s 快冲刺（当前慢跑配速 ×1.2~1.3）+ 90s 慢走 ×6~10（每周 ≤1 次，与力量日错开）
- 「周跑量增幅 ≤10%」是经验法则、无高质量证据证明防伤；关注疼痛、睡眠与总负荷，每 3~4 周安排减量

户外力量角（公园单双杠）：

- 引体向上｜降阶：弹力带辅助、离心引体、澳洲划船（低杠）
- 双杠臂屈伸｜降阶：跳跃助力、腿前屈减小幅度
- 悬垂举腿、斜身划船、台阶跳箱（稳固台阶）

跑鞋与安全：选缓震跑鞋；避免连续在硬水泥地大跑量；夜跑穿反光衣物；跑前动态热身（见 `technique.md` §一），跑后静态拉伸。

### 骑行

定位：低冲击有氧，适合大体重、膝盖不适或想替代跑步的人；通勤骑行也算日常活动量。

- **入门量**：每周 3 次、每次 20~40min 平路，能轻松完成后加到 60min；总周量对齐每周 150~300min 中等强度。**「新手每天骑多少公里」没有权威标准**，按「骑完还能正常说话、第二天不酸」加量（教练共识）
- **踏频**：平路保持 70~90 rpm，爬坡可降到 50~70 rpm；用变速而不是硬踩，保护膝关节
- **强度判断**：RPE 5~6（10 分制）、能说完整句子为中等；想加间歇用「快骑 1min + 慢骑 2min」×6~8
- **安全（共识）**：头盔必戴；前后灯 + 反光；靠右不逆行；出发前查刹车/胎压/快拆；避免夜间、雨天、大车流路段；新手不锁踏；长距离带补给与备胎并告知路线
- 室内功率单车按 §有氧器械执行

### 游泳

定位：关节压力最小的有氧，特别适合大体重减脂人群、膝盖不适者。

- 技术优先于距离：先学自由泳打腿与划臂分解，能连续游 200m 再谈训练
- 强度控制：谈话测试（间歇末尾能说短句）或 RPE 6~8
- 间歇课表示例（30~40min，配速属**教练共识**、个体差异大）：
  - 热身：200m 任意泳姿慢游 + 50m 打腿 ×2
  - 主项：50m ×8~10（组间 20~30s，约 1:10~1:40/50m 为常见新手区间），或 100m ×4~6（组间 30~45s）
  - 单次总量 600~1000m，每周 2~3 次；配速标准是**动作不变形、能连续完成**，不是追时间
  - 放松：100~200m 慢游
- 进阶：缩短休息、延长单程（50m→100m→200m）、加入划水掌/夹板腿
- 安全：避免饱腹、饮酒、疲劳或低温时下水（「饭后 1 小时不能游泳」缺强证据，但饱腹下水确实不适）；下水前 5min 热身肩关节；公开水域必须结伴、佩戴浮具（跟屁虫）、避开暗流/水草/船只航道、不在雷雨与低温时下水、告知路线与返回时间（WHO 溺水预防共识）

### 徒步

定位：低强度长时间有氧 + 负重下的下肢耐力，减脂与心肺底子都好用。

- **负重**：新手控制在体重的 10%~15%，有训练基础者 ≤20%，不建议长期超过 25%~30%（**户外教育共识，无权威统一标准**）；背包 5kg 起，每 2 周加 1~2kg
- **强度**：上坡控制心率在中等强度（64%~76% HRmax），能说话不喘；下坡用登山杖可减轻下肢负荷与肌肉损伤约 10%~25%（证据中），改善平衡
- **步法**：小步高频，全脚掌落地，下坡膝盖微屈缓冲
- **周计划融合**：工作日爬楼梯/坡走 30~40min 替代；用户周末可安排时，周末一次长线徒步（2~4h），周末不可训练则把长线拆为周五加长或两次中程
- **补水与补给**：出发前 2 小时约 500ml；途中每 15~20min 150~250ml；>60~90min 或大量出汗补电解质（钠 300~600mg/L）；长线每小时补 30~60g 碳水；以体重下降 <2% 为脱水控制目标
- **装备与安全**：登山鞋、1L 水/2h 起步、电解质、下坡护膝（有膝伤史）、结伴并告知路线
- **恢复日**：徒步次日做髋屈肌与小腿拉伸，可安排散步等主动恢复

### 其他常见运动（羽毛球 / 爬山 / 球类 / 跳绳）

- 定位：这些运动按「有氧 + 间歇」处理，不能替代力量训练；每周 1~2 次即可，注意与力量日错开。
- 羽毛球/球类：多方向移动与急停多，先做踝髋热身，穿防滑场地鞋；有膝踝旧伤者控制强度与频次。
- 爬山：按 §徒步的原则（负重、心率、下坡护膝）执行。
- 跳绳：按 §有氧器械的参数（30~60s × 8~10 组）执行。

## 混合状态排期原则（多运动状态组合）

用户有多种运动状态（如工作日家里 + 周末健身房、力量在健身房 + 有氧在户外）时：

1. 需要器械的复合主力动作（深蹲/卧推/硬拉）排在健身房日
2. 非健身房日（室内无器材 / 家庭 / 室外）做辅助与薄弱部位 + 自重或户外有氧
3. 保持每周同一肌群训练节奏，不因状态切换打乱频次
4. 同一肌群两次力量训练仍间隔 ≥48h；有氧不挤占力量日恢复
