# 推荐模板库（按需加载）

> 仅在用户索要「现成模板 / 推荐方案 / 照着练的计划」时读取本文件。模板只提供**排期与差异项**，动作与起始重量按 `venues.md` 的 BW 折算表取值，热量与蛋白质按 `SKILL.md` 第 2 步口径计算，输出后仍走第 7 步动态调整；模板与用户实测恢复期冲突时，以实测为准。

---

## 选型

| 体型 / 需求 | 用哪个 |
|---|---|
| 一般增肌减脂 · 薄肌身材（每周 4 练，健身房/家庭器械） | 排期一 |
| 瘦胖子（体重正常、体脂超标、腰腹/胸堆积）· 减腰脂 + 改善脂肪胸 | 排期二 |
| 每周固定 3 次力量 · 背/腿/胸单部位（每周 3 练） | 排期三 |
| 居家 / 出差 / 宿舍 · 无器材自重（每周 3~4 练） | 排期四 |

## 共享总则（所有排期沿用）

- **力量为主、有氧为辅**：力量 3~4 次/周；有氧按目标分档——减脂 2~3 次/周，增肌/重组 1~2 次/周；每次 20~40min（新手 ≤30min），可练后做或独立时段
- **分化**：按每周可训练天数选（2~6 天，见 `programs.md` §常见训练分化方式）；同等频次优先全身/上下分化（肌群频率更高），推拉腿适合每周 5 天以上。与性别无关，按经验、恢复与时间定
- **容量**：每肌群每次 1~2 个动作 ×4~5 组；单次总组数 ≤20 组；每肌群**每周 10~20 个正式组**为增肌有效区间（频次低时每肌群加到 2 个动作）
- **核心收尾**：每个力量日末尾练核心 3 组（下腹 / 侧腹 / 上腹按核心分区轮换）
- **组间休息**：复合动作（深蹲、硬拉、卧推、划船、推举）2~3min；孤立动作 60~90s
- **恢复**：同一肌群两次力量训练间隔 ≥48h（高强度大肌群 72h）；用户有实测恢复期时以实测为准
- **营养与恢复**：热量与蛋白质按 `SKILL.md` 第 2 步的目标口径，不在此重复；睡眠 7~9h；进度看腰围 + 照片 + 力量曲线，不只看体重
- **说真话**：局部减脂不成立，练胸/练腹是塑形不是定点烧脂；乳头后方摸到硬橡胶感硬块或有胀痛、疑腺体发育 → 先就医查激素（见 `goals.md` §局部塑形）

## 排期一：增肌减脂 · 薄肌身材（每周 4 练）

| 星期 | 训练 | 内容 |
|---|---|---|
| 周一 | 腿A（蹲·重） | 深蹲 4×8~12、腿举 3×10~15、臀推 3×10~12、腿弯举 2×12~15 ＋ 核心 3 组 |
| 周二 | 上肢A（胸+三头） | 上斜哑铃卧推 4×8~12、双杠臂屈伸 3×8~12、绳索下压 3×12~15 ＋ 核心 3 组 |
| 周三 | 有氧 + 主动恢复 | 坡走或慢跑 20~40min（按 `venues.md` §跑步机），或散步 |
| 周四 | 腿B（髋+单侧·中轻） | 背屈伸 3×12~15、箭步蹲 3×10~12/侧、腿弯举 2~3×12~15 ＋ 核心 3 组 |
| 周五 | 上肢B（背+肩+二头） | 高位下拉 4×10~12、坐姿划船 4×10~12、坐姿推肩 4×8~12、反向蝴蝶机飞鸟 3×12~15、弯举 2×10~15 ＋ 核心 3 组 |
| 周六/日 | 主动恢复 / 休息 | 散步、拉伸；步数 ≥8000 |

## 排期二：瘦胖子版（腰部脂肪 + 脂肪胸）＝ 排期一 ＋ 差异项

适用：体重/BMI 正常但体脂超标、脂肪堆积在腰腹与胸部的「瘦胖子」（隐性肥胖，见 `goals.md` §减脂增肌与 §局部塑形）。在排期一基础上只改四点：

- **饮食**：热量 ≈ TDEE（±100）；蛋白质 2.0~2.4 g/kg（重组期口径）；碳水由剩余热量决定（约 2~3 g/kg），不另设固定克数；总热量以第 2 步 TDEE 口径为准
- **有氧**：每周 2~3 次中等强度——默认周三 1 次 + 力量日练后 20min ×1~2 次，不占用周末；仅当用户同意周末训练时，才在周六加 1 次
- **胸课强化上胸与胸外延**：上斜哑铃卧推 / 上斜飞鸟 / 夹胸为主，双杠臂屈伸（前倾）兼顾下胸；胸保持每周 2 次（练胸与练背不同日）
- **核心**：按核心分区轮换（下腹 / 侧腹 / 上腹各 3 组；新手从过渡区入手）

## 排期三：三分化（背 / 腿 / 胸 · 每周 3 练）

背/腿/胸隔天排（如周一背、周三腿、周五胸），其余日有氧 ≤30min 或休息；力量日末尾按核心分区做 3 组。

| 日 | 内容 |
|---|---|
| 背部日 | 高位下拉 4×10~12、坐姿划船 4×10~12、单臂划船 3×10~12、弯举 3×12 ＋ 核心 3 组 |
| 腿部日 | 背向哈克深蹲 4×12、火箭推 3×20、腿弯举 3×12 ＋ 核心 3 组 |
| 胸部日 | 史密斯平板卧推（座椅调平，落点锁骨与胸之间偏下）4×10~12、史密斯上斜卧推（座椅 30°/45°，落点锁骨正下方偏下，重量≈平板 80~90%）4×10~12、俯卧撑 3×10~12（降阶：跪姿）＋ 核心 3 组 |

组间休息：复合动作 2~3min（深蹲类吃力可放到 3min），孤立动作 60~90s。

## 排期四：无器材版（居家 / 出差 / 宿舍 · 每周 3~4 练）

适用：完全没有器材、临时出差或宿舍场景。结构 = 自重全身力量 3 次 + 有氧 1~2 次 + 核心收尾；不走 BW 折算（无器械负重），动作降阶与替代见 `venues.md` §无器材健身。

| 星期 | 训练 | 内容 |
|---|---|---|
| 周一 | 全身 A（推蹲为主） | 俯卧撑 4×8~15（降阶：跪姿/上斜推墙）、自重深蹲 4×15~20、保加利亚分腿蹲 3×10~12/侧、平板支撑 3×30~45s |
| 周二 | 有氧 + 步数 | 走跑结合或慢跑 30min（心率 Zone 2；坡度配速见 `venues.md` §跑步机 / §户外与跑步）；无场地改开合跳 + 登山跑间歇 20min；日步数 ≥8000 |
| 周三 | 全身 B（拉髋为主） | 引体向上或毛巾门缝划船 4×6~12（降阶：离心引体）、单腿罗马尼亚硬拉 3×10/侧、臀桥 3×15~20、侧支撑 3×20~40s/侧 |
| 周四 | 休息 / 主动恢复 | 散步、全身拉伸（与周三、周五训练日各间隔 ≥48h） |
| 周五 | 全身 C（循环体能） | 波比跳 3×10~15、派克俯卧撑 3×8~12、分腿蹲 3×12/侧、登山跑 3×20~30s、死虫式 3×10/侧 |
| 周六/日 | 主动恢复 / 休息 | 散步、拉伸；步数 ≥8000 |

组间休息 60~90s；有伤病史按第 1 步采集结果替换动作（膝伤 → 箱式深蹲替代深蹲、腰伤 → 鸟狗式替代卷腹类）。

**自重进阶四板斧（次数上限打满且轻松 = 升级到下一档）**：

1. **变式升级**：跪姿 → 标准 → 脚垫高俯卧撑；臀桥 → 单腿臀桥；深蹲 → 分腿蹲 → 保加利亚分腿蹲
2. **负重**：背包装书/水瓶（每次 +2~3kg）
3. **节奏**：放慢离心至 4 秒下放
4. **密度**：缩短组间休息（90s → 60s → 45s）

用户从排期四起步、后续办了健身房的：迁移到排期一，起始重量按 BW 折算表重新校准（第一次训练宁轻勿重）。

## 输出范例（一周逐日课表）

> 以下示例仅供格式参考，数值须按用户实际数据重算；心率按 Tanaka 公式 $208-0.7\times年龄$ 的 60~70% 计算（示例按 30 岁 → 约 112~131）。

| 星期 | 训练内容 | 动作(组×次·起始重量) | 组间休息 | 强度备注 |
|---|---|---|---|---|
| 周一 | 全身 A（推为主） | 上斜哑铃卧推 4×8~12（单边 12~14kg 起）、哑铃肩推 3×10~12（单边 8~10kg 起）、绳索下压 3×12~15（12~19kg） | 复合 2~3min / 孤立 90s | RPE 7~8；12 次打满余力足 → 哑铃 +2kg |
| 周二 | 有氧（跑步机） | 慢跑 30min：坡度 1%、7.5~8.5 km/h，心率 112~131 | — | 或坡走 10~12% + 5.0~5.5 km/h；跑完做谈话测试 |
| 周三 | 全身 B（腿背为主） | 杠铃深蹲 4×8~12（40~55kg 起）、高位下拉 4×10~12（32~39kg 起）、哑铃 RDL 3×10~12（单边 12~15kg 起） | 复合 2~3min | 先做 5~10min 动态热身（见 `technique.md`） |
| 周四 | 有氧（跑步机） | 走跑结合 30min：慢跑 3min @ 1%、7.5 km/h + 快走 2min @ 6.0~6.5 km/h ×6 组 | — | 心率 112~131，能说完整句子 |
| 周五 | 全身 C（推拉平衡 + 核心） | 平板哑铃卧推 4×8~12（单边 12~15kg 起）、坐姿划船 4×10~12（32~39kg 起）、保加利亚分腿蹲 3×10/侧（自重起）＋ 核心 3 组 | 复合 2~3min / 孤立 90s | 弱项补强 |
| 周六 | 主动恢复 | 散步 30min 或全身拉伸 15min，步数 ≥8000 | — | 不排力量与间歇 |
| 周日 | 完全休息 | — | — | 睡眠 7~8h |
