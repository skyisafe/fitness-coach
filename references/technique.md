# 训练技术参考：热身 · 8 个核心动作 · 呼吸 · 护具 · 恢复 · 疼痛分流

> **何时读取本文件**：用户是新手或第一次练自由重量、问「这个动作怎么做」「膝盖内扣/圆背/塌腰怎么办」「要不要戴腰带」，或计划里出现深蹲/卧推/硬拉等复合动作时读取。本文件只写技术细节，工作流、公式与排期仍按 SKILL.md 与 venues.md。

## 一、训练前热身（5~10 分钟）

顺序固定：**升温 → 关节活动 → 动作模式演练**。目的不是拉长肌肉，而是让关节与神经「上线」。

| 环节 | 时长 | 内容 |
|---|---|---|
| 升温 | 2~3 min | 快走、单车、划船机，微微出汗即可 |
| 关节活动 | 2~3 min | 踝绕环、髋绕环、胸椎旋转、肩绕环，每个方向 8~10 次 |
| 动作模式演练 | 2~4 min | 当天首个动作空杆/自重 1~2 组 × 8~12 次，再加臀桥、死虫式、弹力带侧向走做激活 |

**首个复合动作必须做递增组（ramp-up）**：空杆或极轻 → 约 40% → 60% → 75% → 85% 工作重量，每组 5~10 次、组间 1~2 min，共 2~4 组。作用是神经激活与动作复习，不是练到累；大重量日（≥85% 1RM）建议 3~5 组。

**训练前不做长时间静态拉伸**：单个肌群静态拉伸 >60 秒会让随后力量/爆发力下降约 **4.0~7.5%**；≤60 秒影响很小（约 1~2%）。静态拉伸放到训练后或单独时段（Chaabene 2019，中）。

- **判断热身够不够**：第一组就感觉关节发紧、动作发僵 = 不够，回去补 1~2 组递增组；完全不热、心率没上来 = 升温不足，先加 2 分钟轻有氧。

## 二、8 个核心动作技术要点

> 全部属教练认证**教材共识**（NSCA / ACSM / ACE），非 RCT 证据；cue 是可执行提示语，不是「唯一正确姿势」。通用判断标准：**脊柱中立 + 不憋气**，姿势一崩就停。

### 1. 杠铃深蹲
- **要点**：①脚掌三点压地（大脚趾根、小脚趾根、脚跟），膝对准第二脚趾 ②吸气收紧腹部，肋骨不外翻 ③髋膝同时下、先屈髋后屈膝 ④下到髋略低于膝或能保持中立脊柱的最低点，起身「用脚把地推开」
- **常见错误**：膝内扣（未激活臀中肌/髋外展）；腰椎后倾（「屁股眨眼」）仍勉强加深
- **安全提示**：深度以腰不弯为准；蹲不深就减重量或垫高脚跟，不靠憋气硬撑行程

### 2. 杠铃 / 哑铃卧推
- **要点**：①肩胛骨后缩下沉，「把背压进凳子里」 ②握距使前臂在底部垂直地面 ③杠下落到乳线附近，肘约 45~75° ④脚踩实、臀部不离凳，推起时略向后上方
- **常见错误**：肘完全外展 90°（肩峰撞击风险）；臀部离凳拱腰代偿
- **安全提示**：无保护者时不要用接近极限的重量；哑铃最后几下先收回到膝盖再起身

### 3. 传统硬拉
- **要点**：①杠在脚掌中部上方，小腿距杠约 2~3 cm ②髋高于膝、肩略高于髋，背阔肌「把杠拉向身体」 ③起杠前先「绷紧杠」消除间隙 ④推地＋伸髋同步，杠贴腿走，锁定时站直、不后仰
- **常见错误**：起杠时弓背（腰椎屈曲负荷）；杠离身体过远（力臂变长，腰更吃力）
- **安全提示**：腰一弓就结束这一组，宁可减重量也不「先拉起来再说」

### 4. 罗马尼亚硬拉（RDL）
- **要点**：①微屈膝并固定膝角（下放全程膝角不再变） ②髋向后推，「用臀去找身后的墙」 ③杠贴大腿下滑，到腘绳肌明显牵拉（约膝下~小腿上段）即止 ④起身靠伸髋，不靠腰
- **常见错误**：弓腰追求更大行程；做成「直腿硬拉」导致膝锁死＋腰代偿
- **安全提示**：手够不到小腿中部很正常，行程上限是腰保持中立

### 5. 高位下拉
- **要点**：①握距略宽于肩，先沉肩再下拉 ②想象「用肘把杠拉向身体两侧」 ③拉到锁骨/上胸即止 ④回放 2~3 秒控制离心，躯干后倾 ≤15°
- **常见错误**：颈后下拉（肩关节极端外旋＋前伸）；靠身体摆荡完成次数
- **安全提示**：颈后下拉没有额外收益，一律改到胸前

### 6. 坐姿划船
- **要点**：①胸口挺起、脊柱中立 ②先收肩胛再拉，肘贴身向后，把手柄拉到腹部 ③末端停 1 秒挤压肩胛 ④离心缓慢回到手臂伸直、肩胛前伸
- **常见错误**：耸肩发力（上斜方代偿）；腰部前后晃荡借力
- **安全提示**：有腰伤史者降一档阻力，用肩胛与胸椎发力，不靠腰前后甩

### 7. 站姿 / 坐姿肩推
- **要点**：①肋骨下沉、核心收紧，避免腰椎过伸 ②起始位肘略前于身体、前臂垂直 ③推起时头略后让位，杠过头顶后收下巴 ④下落到下巴/锁骨高度即止
- **常见错误**：腰椎过度后仰（做成「站姿上斜推」）；推举路径过于靠前导致肩前疼痛
- **安全提示**：肩有旧伤改坐姿＋靠背，或换哑铃中立握（掌心相对）

### 8. 平板支撑
- **要点**：①肘在肩正下方、前臂平行 ②骨盆后倾一点（「尾骨收向肋骨」）激活腹肌 ③臀腿收紧，不塌腰不撅臀 ④呼吸不憋气，以「动作变形」而非计时为停止标准
- **常见错误**：塌腰（腰椎过伸负荷）；憋气＋抬头（颈椎过伸）
- **安全提示**：20~45 秒 × 3~5 组已足够，撑到发抖变形不如多做一组

## 三、呼吸与 Valsalva

| 场景 | 怎么呼吸 |
|---|---|
| 普通训练（多数人、多数组） | 发力（向心）呼气、下放（离心）吸气；或全程自然呼吸 |
| 核心 / 大重量组 | 可「轻闭气 1~2 秒即呼」，不长时间屏气 |
| Valsalva（吸气后闭气发力） | 仅限健康、有经验者在大重量（≥80% 1RM）深蹲/硬拉的最后 1~2 组短时使用：吸气 → 闭气过难点 → 立即呼气 |

- Valsalva 能提高躯干刚性与最大力量，但会让血压短时明显升高（收缩压可到 200+ mmHg）（共识：ACSM）。
- **谁不能用**：高血压（无论是否已控制）、冠心病/心衰/脑血管病、主动脉瘤、增殖期视网膜病变、孕期 → 一律「发力时呼气」，不憋气。
- 实操判断：需要靠憋气才做得起来 = 重量超了，先降重量再谈呼吸。
- **组间**：恢复自然呼吸、不连续屏气；有高血压、心血管病、孕期等情况的用户，整套动作都按「发力呼气」执行（细则见 `populations.md` §五、已控制高血压 / 2 型糖尿病）。

## 四、护具：什么时候有用

| 护具 | 有用 | 不必用 / 代价 |
|---|---|---|
| 举重腰带 | 大重量（约 ≥80% 1RM）深蹲、硬拉组 | 轻负荷、孤立动作、日常训练不必；不能替代核心训练；长期全程佩戴可能削弱自主稳定（证据有限） |
| 助力带 | 握力成为限制因素时：大重量硬拉、RDL、高次数划船 | 减少握力与前臂刺激，建议只在最后几组或大重量组用 |
| 护膝 / 护腕 | 旧伤、关节不稳、大重量比赛 | 无普遍预防损伤的证据，不是新手必需装备 |
| 深蹲鞋（后跟抬高） | 踝背屈受限者，能改善深度与躯干直立度 | 普通训练者平底硬底鞋即可；跑鞋软底不适合深蹲/硬拉 |

- **任何护具都不要宣称「防伤」**：腰带能提高腹内压与躯干刚性（生物力学证据），但「腰带/护具预防损伤」缺乏高质量前瞻证据（证据有限）。
- 优先级永远是动作质量 > 护具；动作错误带来的风险，护具补不回来。

## 五、冷身与恢复

- **冷身**：训练后 3~5 分钟低强度（慢走、慢踩车）帮助心率血压平稳回落、促进主观放松；但**不减少 DOMS、不加速力量恢复**（证据有限，阴性证据为主）——不要承诺「冷身能防酸痛」。
- 睡眠 7~9 h 是最有效的恢复手段；蛋白按 SKILL.md 的目标吃够。
- 主动恢复（散步、轻有氧）能缓解僵硬感，但不改变肌肉损伤的修复时程。

## 六、疼痛分流：DOMS 还是损伤

| 判定维度 | DOMS（正常，可继续练） | 损伤性疼痛（停练、就医） |
|---|---|---|
| 出现时间 | 练后 24~72 h 达峰，3~5 天自愈 | 动作中即刻出现；或 48~72 h 不缓解 / 持续加重 |
| 对称性 | 双侧对称 | 单侧为主 |
| 定位 | 弥散、按压酸痛 | 定位明确，某动作某角度刺痛 |
| 活动后变化 | 轻度活动后减轻 | 越动越疼、活动后加重 |
| 伴随表现 | 无肿胀、力量正常 | 肿胀发热、弹响、打软腿、麻木无力、关节交锁 |

**处理**：DOMS → 低强度活动 + 睡好 + 吃够蛋白，可继续训练但同肌群间隔 ≥48 h；疑似损伤 → 停该动作、早期 RICE、48~72 h 无改善就医。

**直接就医（不停留在问训练）**：夜间痛/静息痛、关节明显肿胀发热、交锁或打软腿、麻木/无力/放射痛、外伤后无法负重、发热伴关节痛、胸痛/晕厥/异常气短、不明原因体重下降。

**筛查工具不能预测伤病**：FMS 等动作筛查的损伤预测效度不足（证据有限），它的用途是发现需要改动作或就医的问题，不是「预测谁会受伤」。

## 七、训练前 / 中 / 后自检清单

**训练前**
- [ ] 5~10 分钟动态热身做完（升温＋关节活动＋动作模式演练）
- [ ] 首个复合动作完成 2~4 组递增组，最后一组接近工作重量但不产生明显疲劳
- [ ] 没有做单肌群 >60 秒的长时间静态拉伸
- [ ] 睡眠不足、生病或明显疲劳 → 今天降一档强度，不冲大重量（经验性建议，证据有限）

**训练中**
- [ ] 每个动作第一组先确认两件事：脊柱中立、不憋气
- [ ] 姿势一崩（弓腰、膝内扣、塌腰、耸肩）立刻停这一组，不硬撑次数或时间
- [ ] 只有大重量复合动作才考虑短时 Valsalva，其余动作一律发力呼气
- [ ] 组间按 SKILL.md 的休息时长执行，恢复呼吸后再做下一组

**训练后**
- [ ] 3~5 分钟低强度冷身（可选；只助放松，不承诺防酸痛）
- [ ] 睡眠 7~9 h、蛋白吃够（数值按 SKILL.md）
- [ ] 记录动作 × 重量 × 次数 × 组数，作为下次加重量或加组的依据
