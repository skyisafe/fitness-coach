# 体成分数据提取与解读（体脂秤 / InBody / 体检报告）

当用户提供近期身体数据（文字或图片）时读本文件。流程固定三步：**原始转写 → 标准格式转化 → 联动解读**，顺序不可跳过。数字口径与证据强度以 `references/evidence.md` 为单一事实源；本文件只解决「怎么转写、怎么映射、怎么解读」。

## 使用前：隐私与边界

- **照片处理**：用户发来的体脂秤截图、InBody 单据、体检报告照片，只在本地/当次对话内读取与转写，**不主动外传、不上传第三方**；建议用户先对姓名、住址、病历号等敏感信息打码或涂改。
- **不构成诊断**：BIA（生物电阻抗）是估算设备，不是医学检查；肥胖症、肌少症、骨质疏松、代谢综合征的判定以医院检查（含 DXA）为准。
- **本文件职责**：把设备读数翻译成训练可用的分级与提示，不替医生下结论，也不靠单一数值吓人。
- **适用范围**：只处理体成分类数据（体脂秤 App、InBody、体检报告的体成分页）。血常规、肝肾功能、激素、甲功等化验指标不在本文件解读范围，出现异常值直接建议就医。

## 第一步：原始数据转写

- 文字：逐项照抄，保留原始名称与单位（如「骨骼肌量 21.5kg」）
- 图片（体脂秤 App 截图、InBody 单据、体检报告照片）：
  - 逐项读图转写，按报告上的顺序列出
  - 模糊、遮挡、反光看不清的字段标「识别不清」，向用户确认，**不得编造或脑补数字**
  - 多次读数 / 多页报告取**最新一次**；有测量日期就一并记录
  - 常见品牌（小米 / 云麦 / 有品 / 华为 / InBody）字段名不同：转写保留原名，转化时统一映射
  - 一并记录**测量条件**（日期、晨起/训练后、空腹与否、是否同一台设备）——BIA 结果对水分与进食敏感，条件不同不可直接对比

**转写自检三道关（转写完立即执行，任何一道不过就复查图片或向用户确认）**

1. **自洽公式**：体重 ≈ 体脂肪量 + 总水分 + 蛋白质 + 无机盐（±0.3kg）；去脂体重 = 体重 − 脂肪量。对不上说明有数值读错
2. **数量级常识**：腿部肌肉量应明显大于手臂（腿是最大肌群）；躯干肌肉量占比最大；内脏脂肪等级常见 **≤20**（厂商口径），**≥15 已属高值、需复核**——但只提示「待确认」，不判为读错
3. **关键数值确认**：体脂率、内脏脂肪等级等主指标在回复中列出原始值，并注明「已按图片转写，如与报告不符请指出」

**测试者信息校验**：报告上的身高、年龄、性别与用户自述不一致时（常见：机器里身高填错），以**用户自述为准**参与后续计算，报告打印的派生指标（BMI 等）作废重算，并提醒用户下次测试前修正机器信息。

## 第二步：转化为标准格式

输出时**先列原始数据，再列标准格式**。标准格式固定 7 项（缺失项标「未提供」，不得估算冒充实测）：

```
体重(kg):
体脂率(百分比):
肌肉率(百分比):
身体水分(百分比):
蛋白质含量(百分比):
内脏脂肪等级(注明设备刻度 1~12 或 1~30):
骨盐量(kg):
```

映射与换算规则：

| 原始字段 | 目标字段 | 换算 |
|---|---|---|
| 体重 | 体重(kg) | 原值 |
| 体脂率 / 脂肪率 | 体脂率(百分比) | 原值 |
| 肌肉率 | 肌肉率(百分比) | 原值 |
| 肌肉量(kg) | 肌肉率(百分比) | ÷ 体重 × 100 |
| 骨骼肌量(kg)（InBody） | 肌肉率(百分比) | ÷ 体重 × 100，并注明「骨骼肌口径」 |
| 水分率 / 身体总水分 | 身体水分(百分比) | 原值 |
| 蛋白质(kg) | 蛋白质含量(百分比) | ÷ 体重 × 100 |
| 蛋白质(%) | 蛋白质含量(百分比) | 原值 |
| 内脏脂肪等级 / 指数 | 内脏脂肪等级(按设备刻度) | 原值（厂商评级，不是面积） |
| 内脏脂肪面积(cm²)（InBody） | 内脏脂肪等级(按设备刻度) | **不换算**，保留 cm² 并注明：≥100cm² 出自日本 JASSO（CT 口径），中国官方只用腰围 |
| 骨盐量 / 骨量 / 骨矿含量 | 骨盐量(kg) | 原值（BIA 估算的骨矿物质含量，不是骨密度） |

- **单位与口径坑**：报告给的是「脂肪量 kg」而 7 项要 %，先换算再进表；「肌肉量」与「骨骼肌量」是两个口径（后者才是 InBody 的 SMM），一律在数值后注明，避免把骨骼肌率当肌肉率解读

换算后快速自检：体脂率与换算肌肉率是**不同口径**，不可相加凑 100%（体重 = 体脂肪 + 去脂体重；去脂体重 = 水分 + 蛋白质 + 矿物质，不是「肌肉」）；若体脂率 30% 而肌肉率仅 25% 这类明显矛盾，提示读数或换算有误，复查图片。

**机器口径差异（重要）**：BIA 的「肌肉量」是回归模型推算值，**不是「水分 + 蛋白质」**——去脂体重才等于「水分 + 蛋白质 + 矿物质」。部分健身房大型体测机的「肌肉量」按软瘦体重口径，换算出的「肌肉率」可达 60~75%，与家用秤 40~60% 的参考带**不可互相比较**。换算值明显超出参考带时不要判异常：标注口径，并优先用报告自带的「节段肌肉评价」（低标准 / 标准 / 高标准）判读。

## 第三步：各字段参考范围与解读

**总则**：家用体脂秤为 BIA 原理，误差 ±3~8%，各品牌算法不同——**看趋势、看组合，不迷信单次绝对值，不跨设备横比**。下表区间均为参考值，不是诊断标准。

| 字段 | 参考区间 / 判读口径 | 证据强度 |
|---|---|---|
| BMI | <18.5 偏瘦；18.5~23.9 正常；24.0~27.9 超重；≥28 肥胖（**中国 2024 标准，不用 WHO 25/30**） | 强（WS/T 428-2013 / 成人肥胖食养指南 2024） |
| 腰围 | 中心型肥胖**前期**：男 85~89.9、女 80~84.9 cm；中心型肥胖：男 ≥90、女 ≥85 cm。**不用 IDF 女性 80cm 当肥胖切点** | 强（同上） |
| 体脂率 | 无中国官方切点。参考区间：男 10%~20%、女 20%~30%（随年龄上移）；男 >25%、女 >32% 偏高（Gallagher 2000 / ACE 行业表） | 中（Gallagher）/ 弱（ACE） |
| 肌肉率 / 骨骼肌 | 无通用参考范围；报告「标准范围」= 理想骨骼肌量的 90%~110%，属**厂商模型**。权威替代：AWGS 2019 的 ASM/身高²，BIA 男 <7.0、女 <5.7 kg/m² 提示肌肉量偏低 | 厂商模型 / 强（AWGS 2019） |
| 身体水分 | 男 50%~65%、女 45%~60%（行业参考）；偏低多为脱水，先补水复测 | 弱（厂商 / 行业） |
| 蛋白质含量 | 16%~20%，**设备估算值**；偏低多与肌肉量不足同步 | 厂商模型 |
| 内脏脂肪等级 | 厂商专有评级（如 Tanita 1~12 为健康档、≥13 偏高；1~30 刻度设备以说明书健康档为准），**不可跨设备、不等于面积**；同一设备纵向上升 ≥2 级即复核。100cm² 是日本 JASSO 标准，中国官方只用腰围 | 厂商模型 / 强（中国无内脏脂肪面积标准） |
| 骨盐量 | BIA 估算的**骨矿物质含量，不等于骨密度**；骨质疏松用 DXA 的 T 值（≤−2.5）判定；只可看长期趋势 | 中（含义）/ 弱（参考范围） |

解读要点：

- **体脂率**：只作趋势参考；体重正常但体脂落在偏高区间 → 「隐性肥胖 / 瘦胖子」，目标定为增肌塑形而非减重。**不写「标准 / 正常值」**，也不与不同设备或健身房体测机横比
- **肌肉率**：品牌差异最大的一项，与水分、蛋白质联动判断比单看可靠；怀疑肌肉量偏低时按 AWGS 2019 的 ASM/身高²口径提示，需确诊者建议就医做 DXA
- **身体水分**：BIA 脱水时阻抗升高，**体脂率被高估、肌肉率被低估**；提示先补水、晨起空腹复测后再解读
- **蛋白质含量**：设备估算，偏低提示肌肉量不足；**蛋白摄入目标不在本文件给**，按 SKILL.md 第 2 步计算（区分减脂 / 增肌 / 重组口径）
- **内脏脂肪等级**：仅作同设备趋势；内脏脂肪风险以**腰围**为核心（中国官方口径），不把设备等级当医学诊断
- **设备评级只是提示**：报告上印的「标准 / 偏高 / 偏低」是各厂商模型给的区间，不是医学判定；同一数值换一台机器可能变档，只用于该设备的纵向趋势
- **骨盐量**：短期基本不随训练变化，不作训练 KPI；长期偏低且蛋白质偏低 → 关注钙与蛋白摄入，中老年女性或长期偏低者建议查骨密度（DXA），**不据 BIA 骨量自行补钙或恐慌**

## 联动解读规则（提炼 2~4 条关键问题写进分析）

1. 水分偏低 → 先提示「补水后晨起复测再解读」，当前体脂率按偏高 1~2% 看
2. 肌肉率偏低 + 蛋白质偏低 → 力量训练与蛋白摄入第一优先级（蛋白目标按 SKILL.md 第 2 步），减脂者防掉肌肉、增肌者上调训练容量
3. 内脏脂肪等级超出该设备自身健康档上限（Tanita 口径 ≥13 偏高；1~30 刻度按说明书）或腰围超前期 / 肥胖切点 → 有氧分配上调（+1 次/周或 +10min）、日步数上调，腰围每 2 周必测
4. 体脂率正常但肌肉率偏低 → 瘦胖子路径：热量 ≈TDEE 小幅盈余，主抓力量曲线（热量口径见 SKILL.md 第 2 步）
5. 肌肉率正常 + 体脂偏高 → 常规减脂方案即可
6. 实测体脂率与 Deurenberg 估算差 >5 个百分点 → 以实测为准；估算仅作无数据兜底
7. BMI、腰围、体脂率、内脏脂肪等级**互相矛盾**时（如 BMI 正常但腰围超标）→ 以「腰围 + 体脂趋势」为准提示内脏脂肪风险，不只看 BMI

## 使用注意

- **实测优先于公式**：有实测体脂率就不再输出 Deurenberg 估算；无实测才用，且必须标「估算值」
- **Deurenberg 边界**：成人式 SEE≈4.1%（1991）；儿童式出自**同一篇 1991 论文**（不是 1999 版），SEE≈4.4%；推导人群为荷兰白人，**中国人群未验证**，跨人群有系统偏差
- 报告自带的 BMR（体脂秤口径）仅参考，计划统一用 Mifflin-St Jeor（见 SKILL.md 第 2 步）
- 去脂体重 = 体重 ×（1 − 体脂率）= 水分 + 蛋白质 + 矿物质，可作蛋白目标与力量预期的参考；**蛋白目标本身按 SKILL.md 第 2 步**
- 7 项数据不全时逐项标「未提供」，**不跨字段反推缺失值**（如用体脂率倒推肌肉率）；数据冲突时报原始值与矛盾点，请用户复核设备
- 本文件**不重复** BMI / BMR / TDEE / 热量与蛋白目标公式：这些一律按 SKILL.md 第 2 步计算，本文件只提供设备读数的转写与解读口径
- 复测条件：同一台秤、晨起空腹排便后、同等饮水，每 2~4 周一次；单次体脂率波动 ±1% 无意义
