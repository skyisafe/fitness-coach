# 体成分数据提取与解读（体脂秤 / InBody / 体检报告）

当用户提供了近期身体数据（文字或图片）时使用本文件。流程固定为三步：**原始转写 → 标准格式转化 → 联动解读**，顺序不可跳过。

---

## 第一步：原始数据转写

- 文字：逐项照抄，保留原始名称与单位（如"骨骼肌量 21.5kg"）
- 图片（体脂秤 App 截图、InBody 单据、体检报告照片）：
  - 逐项读图转写，按报告上的顺序列出
  - 模糊、遮挡、反光看不清的字段标「识别不清」，向用户确认该数值，**不得编造或脑补数字**
  - 多次读数/多页报告取**最新一次**；有测量日期就一并记录
  - 常见品牌（小米/云麦/有品/华为/InBody）字段名不同，转写时保留原名，转化时统一映射

**转写自检三道关（转写完立即执行，任何一道不过就复查图片或向用户确认）**：

1. **自洽公式**：体重 ≈ 体脂肪量 + 水分 + 蛋白质 + 无机盐（±0.3kg）；去脂肪体重 = 体重 − 脂肪量。对不上说明有数值读错
2. **数量级常识**：腿部肌肉量应明显大于手臂（腿是最大肌群）；躯干肌肉量占比最大；内脏脂肪等级通常 ≤15；超出常识的数值先怀疑读错
3. **关键数值确认**：体脂率、内脏脂肪等级等主指标在回复中列出原始值并注明「已按图片转写，如与报告不符请指出」

**测试者信息校验**：报告上的身高、年龄、性别与用户自述不一致时（常见：机器身高信息填错），以**用户自述为准**参与后续计算，报告打印的 BMI 等派生指标作废重算，并提醒用户下次测试前修正机器信息。

## 第二步：转化为标准格式

输出到回复中时**先列原始数据，再列转化后的标准格式**，标准格式固定为以下 7 项（缺失项标「未提供」，不得估算冒充实测）：

```
体重(kg):
体脂率(百分比):
肌肉率(百分比):
身体水分(百分比):
蛋白质含量(百分比):
内脏脂肪等级(1-30):
骨盐量(kg):
```

映射与换算规则：

| 原始字段 | 目标字段 | 换算 |
|---|---|---|
| 体重 | 体重(kg) | 原值 |
| 体脂率 / 脂肪率 | 体脂率(百分比) | 原值 |
| 肌肉率 | 肌肉率(百分比) | 原值 |
| 肌肉量(kg) | 肌肉率(百分比) | ÷ 体重 × 100 |
| 骨骼肌量(kg)（InBody） | 肌肉率(百分比) | ÷ 体重 × 100，并注明「骨骼肌口径」 |
| 水分率 / 身体总水分 | 身体水分(百分比) | 原值 |
| 蛋白质(kg) | 蛋白质含量(百分比) | ÷ 体重 × 100 |
| 蛋白质(%) | 蛋白质含量(百分比) | 原值 |
| 内脏脂肪等级 / 指数 | 内脏脂肪等级(1-30) | 原值 |
| 内脏脂肪面积(cm²)（InBody） | 内脏脂肪等级(1-30) | 不换算，保留 cm² 并注明（>100cm² 视为偏高，≈等级 10+） |
| 骨盐量 / 骨量 / 骨矿含量 | 骨盐量(kg) | 原值 |

换算后快速自检：体脂率 + 换算肌肉率应大致合理（两者是重叠区间，**不可相加凑 100%**，肌肉含水分与蛋白质）；若体脂率 30% 而肌肉率仅 25% 这类明显矛盾，提示读数或换算有误，复查图片。

**机器口径差异（重要）**：部分健身房大型体测机的「肌肉量」= 身体水分 + 蛋白质（软瘦体重口径，男性换算出的「肌肉率」可达 60~75%），与家用秤 40~60% 的参考带**不可互相比较**。遇到换算值明显超出参考带时，不要判为异常——在数值后标注口径，并以报告自带的「节段肌肉评价」（低标准/标准/高标准）作为肌肉状况的判读依据。

## 第三步：各字段参考范围与解读

家用体脂秤为生物电阻抗（BIA）原理，误差 ±3~8%，各品牌标准不一——**看趋势和组合，不迷信单次绝对值**。

- **体脂率**：男 18~39 岁 8~20% 正常，40~59 岁 11~22%；女 18~39 岁 18~28%，40~59 岁 21~32%。超上限 → 偏高；体重正常但体脂超上限 → 「隐性肥胖/瘦胖子」，目标应定为增肌塑形而非减重
- **肌肉率**：男约 40~60%，女约 30~40%（品牌差异最大的一项）。与蛋白质、水分联动判断比单看更可靠
- **身体水分**：男 50~65%，女 45~60%。偏低多因饮水不足、测前运动出汗、饮酒——BIA 脱水时阻抗升高，**体脂率会被高估、肌肉率被低估**，先补水择晨复测再解读
- **蛋白质含量**：约 16~20%。偏低提示肌肉量不足或蛋白摄入不够
- **内脏脂肪等级**（1~30）：1~9 正常；10~14 偏高（有氧与日步数优先级上调，腰围为核心追踪指标）；≥15 高（建议就医查血脂血糖等代谢指标）
- **骨盐量**：男约 2.2~3.2kg，女约 1.8~2.5kg。短期基本不随训练变化，不作训练 KPI；长期偏低且蛋白质偏低 → 关注钙与蛋白摄入，中老年女性建议骨密度检查

## 联动解读规则（提炼 2~4 条关键问题写进分析）

1. 水分偏低 → 先提示「补水后晨起复测再解读」，当前体脂率按偏高 1~2% 看
2. 肌肉率偏低 + 蛋白质偏低 → 力量训练与蛋白摄入第一优先级（减脂者防掉肌肉，增肌者上调容量与蛋白至 2.2 g/kg）
3. 内脏脂肪 ≥10 → 有氧分配上调（+1 次/周或 +10min），日步数目标上调，腰围每 2 周必测
4. 体脂率正常但肌肉率偏低 → 瘦胖子路径：热量 ≈TDEE 小幅盈余，主抓力量曲线
5. 肌肉率正常 + 体脂偏高 → 常规减脂方案即可
6. 实测体脂率与 Deurenberg 估算差 >5 个百分点 → 以实测为准，估算仅作无数据兜底

## 使用注意

- 实测数据**优先于公式估算**参与后续计算：有实测体脂率就不再输出 Deurenberg 估算
- 报告自带的 BMR（体脂秤口径）仅参考，计划统一用 Mifflin-St Jeor 计算
- 去脂体重 = 体重 × (1 − 体脂率)，可作为蛋白目标与力量预期的参考
- 复测条件：同一台秤、晨起空腹排便后、同等饮水，每 2~4 周一次；单次体脂率波动 ±1% 无意义
