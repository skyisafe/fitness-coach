# 营养学 · 体重控制学 · 三餐模板 · 补给品

仅在用户主动要求饮食/补给建议时使用本文件。所有热量与克数换算到用户自身数据（体重、TDEE）后再给出；**热量与蛋白质目标统一按 `SKILL.md` 第 2 步口径**，本文件只给分配、执行与补给细节。

---

## 宏量营养素分配

- **蛋白质**：按 `SKILL.md` 第 2 步的目标（一般 1.4~2.0、增肌 1.6~2.2、减脂 1.8~2.4、重组 2.0~2.4 g/kg 体重/天），均匀分到 3~4 餐，每餐 20~40g；高体脂者按去脂体重/目标体重算。
- **脂肪**：占总热量 20%~30%，不低于 0.6 g/kg（维持激素水平，女性过低会月经紊乱）。
- **碳水**：剩余热量全部给碳水；训练日多、休息日少；优先粗粮、薯类、水果（中国指南建议碳水供能 50%~60%）。
- **膳食纤维** 25~30 g/天（蔬菜 + 粗粮）；饮水 30~40 ml/kg（约 2~3 L）。
- **一般健康供能比参考**（《中国居民膳食指南 2022》/《成人肥胖食养指南 2024》）：蛋白 15%~20%、脂肪 20%~30%、碳水 50%~60%；三餐供能比约 3:4:3。
- 减重期上限：食盐 <5g/天、烹调油 20~25g/天、添加糖 <25g/天。

## 训练前后与空腹训练

- **练前 1~2 小时**：以碳水为主的一餐（30~60g 碳水）+ 少量蛋白；空腹做力量/高强度会明显掉表现。
- **练后 1~2 小时内**：蛋白质 20~40g + 碳水（如鸡蛋 + 香蕉、蛋白粉 + 面包、牛奶 + 米饭）。
- **空腹有氧**：空腹与进食有氧对 24 小时能量平衡与体脂**没有显著差异**——空腹不会让你多减脂；只有低强度、≤60 分钟的走/慢跑/单车，健康人可以空腹做；**力量训练、HIIT、超过 60~90 分钟的有氧建议先吃点东西**。
- **不要空腹训练的人**：糖尿病（尤其用胰岛素/磺脲类）、孕期、有低血糖史、BMI 偏低或进食障碍风险者。

## 免称重的手掌法（用户日常执行用）

每餐构成 = 1~2 掌蛋白质 + 1~2 拳蔬菜 + 1 拳主食 + 1 拇指油脂。比热量计算好执行，优先给这个。

## 三餐模板（早 / 中 / 晚）

### 减脂版（按 `SKILL.md` 第 2 步的热量目标执行）

- **早**：水煮蛋 2 个 + 无糖豆浆/脱脂奶 300ml + 燕麦 40g + 小番茄/黄瓜；中式替换：杂粮粥 1 碗 + 茶叶蛋 1~2 个 + 凉拌菜
- **中**：进餐顺序先菜 → 后肉 → 最后饭；一掌鸡胸/瘦牛肉/鱼虾 + 两拳绿叶菜 + 一拳米饭（杂粮饭更好）；外卖策略：选清汤/蒸煮、酱汁分开、去皮去肥
- **晚**：豆腐/清蒸鱼/虾仁 一掌 + 大量蔬菜 + 半拳粗粮（红薯/玉米/南瓜）；晚餐尽量在 17:00~19:00 完成，睡前 3 小时不再进食
- **加餐（可选）**：无糖酸奶 100~150g、原味坚果 10~15g（约一小把）、低糖水果 1 个（苹果/蓝莓/柚子）
- 忌：含糖饮料、酒精（1g 酒精 7kcal 且优先供能，影响脂肪利用）、油炸、「健康零食」（果蔬干、风味酸奶）

### 增肌版（按 `SKILL.md` 第 2 步的热量目标执行）

- **早**：鸡蛋 2~3 个 + 全脂奶 300ml + 面包/包子/燕麦 + 香蕉 1 根
- **中**：主食 1.5~2 拳 + 肉一掌半（鸡腿肉/牛肉/鱼）+ 蔬菜两拳 + 可加汤
- **练后**：碳水 + 快蛋白（香蕉 + 蛋白粉，或牛奶 + 面包）
- **晚**：正常主食一拳半 + 肉/蛋/鱼 + 蔬菜；睡前可选酪蛋白类：无糖酸奶/牛奶一杯
- 增肌吃不下怎么办：液体热量（牛奶、奶昔、果汁少量）、坚果与牛油果密度高、三餐 + 2~3 次加餐

### 烹饪与外食原则

蒸、煮、炖、烤、快炒（少油） > 煎 > 炸；每日烹调油 20~25g；减钠（盐 <5g）；火锅选清汤锅底 + 蛋白 + 蔬菜，蘸料用醋/海鲜酱替换麻酱。

## 体重控制学要点

- **能量平衡是唯一底层逻辑**：所有方法（轻断食、生酮、代餐）起效都是因为制造了缺口；选用户能长期执行的形式即可，不迷信某种「神奇窗口」。
- **体重波动解读**：单日 ±1~2kg 多为水分（钠摄入、碳水糖原、生理周期、便秘）；女性黄体期可因水钠潴留上涨 0.3~2kg。看每周 3~4 次晨起空腹（排便后）称重的均值，或用同相位对比。
- **平台期处理（体重 2~4 周无变化）**：
  1. 先核查执行：饮食记录是否走样、步数是否下滑、睡眠是否变差
  2. 加日常活动：日步数 +2000
  3. 再动热量：按 `adjustments.md` §进度数据调整的表执行（下调或上调 100~200 kcal 需有对应判定条件，不随意双向给）
  4. 或安排 1~2 周「维持期」：热量回到 TDEE，给心理与依从性喘息；**间歇性能量限制（如 2 周限制 + 2 周维持）有初步研究支持，但证据不强，不要承诺「多吃几天就能突破平台期」**
- **减重速度红线**：持续 >1 kg/周（>100kg 者按 1%/周）→ 上调热量 100~200；伴随乏力、掉发、月经紊乱 → 立即上调并观察。
- **反弹预防（减脂结束）**：用 4~8 周把热量逐步加回 TDEE（每周 +100~150），同时保持力量训练与步数；减脂期养成的习惯不要在结束当天全丢。
- **行为学技巧**：环境设计（家里不囤零食）、固定进餐时间、餐前一杯水、用小盘子、每周允许 1 次自由餐（不是欺骗日暴食）；让用户自己记录饮食与体重，记录本身是最有效的依从性工具之一。

## 补给品（运动营养补充剂）

定位先讲清楚：**锦上添花，不替代吃饭、训练、睡眠**。收益排序：蛋白粉 ≈ 肌酸 > 咖啡因 > 维D/鱼油 > 其他。

### 蛋白粉

- 用途：便捷补足蛋白缺口（不是必需品，肉蛋奶吃够可以不用）
- 类型：乳清浓缩蛋白（性价比首选）、乳清分离蛋白（乳糖不耐/易胀气选这个）、水解乳清（吸收快、贵）、大豆/豌豆蛋白（素食）
- 用法：20~40g/次，练后或任意蛋白不足的时段；用水/牛奶冲，不要用开水
- 换算（USDA）：1 个全蛋≈6.3g 蛋白、1 个蛋清≈3.6g；30g 乳清蛋白粉（按 80% 含量）≈24g 蛋白，约等于 4 个全蛋或 6~7 个蛋清；鸡胸肉 100g≈22~25g 蛋白

### 肌酸

- 首选一水肌酸（Creatine Monohydrate），研究最充分、最便宜的增力补剂
- 用法：每天 3~5g，长期每天吃（训练日与休息日都吃），**不必做冲击期**（可选 20g/天 ×5~7 天快速饱和，肠胃弱者跳过）；时间任意，随餐或随训练均可
- 预期：提升力量与训练容量 → 间接多增肌；初期体重 +1~2kg 是肌肉储水，属正常现象
- 安全性：健康人群长期使用（证据到 30g/天 × 5 年）未见肾、肝损伤；**有肾病或肾功能异常者先咨询医生**；未成年人仅在专业监督、饮食均衡、已过青春期时考虑
- 选购：认准纯一水肌酸，无需买「进阶配方」

### 其他（简述即可，不主动推销）

- 咖啡因：练前约 60min 服 3~6 mg/kg 提升表现；半衰期 3~7 小时，**睡前 6~8 小时停用**；孕期 ≤200mg/天；高血压、心律失常、焦虑、失眠、胃食管反流者慎用或不用
- 维生素 D：日晒不足者 1000~2000 IU/天（先评估膳食与日晒）
- 鱼油：不爱吃鱼者 1~2g EPA+DHA/天
- 电解质：大量出汗（>1h 运动或夏季徒步）时补充
- **明确不推荐**：左旋肉碱「减脂」、酵素、暴汗服、利尿类减脂药、任何三无减脂产品——遇到用户询问要劝退
- 特殊人群（孕期、哺乳期、未成年人、慢性病用药者）：任何补充剂先问医生
