# 营养学 · 体重控制学 · 三餐模板 · 补给品

仅在用户主动要求饮食/补给建议时使用本文件。所有热量与克数换算到用户自身数据（体重、TDEE）后再给出。

---

## 宏量营养素分配

- 蛋白质：减脂期 1.8~2.2 g/kg 体重；增肌期 1.6~2.2 g/kg；均匀分到 3~4 餐，每餐 ≥25~40g
- 脂肪：占总热量 20~30%，不低于 0.6 g/kg（维持激素水平，女性过低会月经紊乱）
- 碳水：剩余热量全部给碳水；训练日多、休息日少；优先粗粮、薯类、水果
- 膳食纤维 25~30 g/天（蔬菜 + 粗粮）；饮水 30~40 ml/kg（约 2~3 L）
- 训练前后：练前 1~2h 吃碳水为主的一餐；练后 1~2h 内 蛋白质 + 碳水（如鸡蛋 + 香蕉、蛋白粉 + 面包）

## 免称重的手掌法（用户日常执行用）

每餐构成 = 1~2 掌蛋白质 + 1~2 拳蔬菜 + 1 拳主食 + 1 拇指油脂。比热量计算好执行，优先给这个。

## 三餐模板（早 / 中 / 晚）

### 减脂版（按 TDEE − 300~500 执行）

- **早**：水煮蛋 2 个 + 无糖豆浆/脱脂奶 300ml + 燕麦 40g + 小番茄/黄瓜；中式替换：杂粮粥 1 碗 + 茶叶蛋 1~2 个 + 凉拌菜
- **中**：进餐顺序先菜 → 后肉 → 最后饭；一掌鸡胸/瘦牛肉/鱼虾 + 两拳绿叶菜 + 一拳米饭（杂粮饭更好）；外卖策略：选清汤/蒸煮、酱汁分开、去皮去肥
- **晚**：豆腐/清蒸鱼/虾仁 一掌 + 大量蔬菜 + 半拳粗粮（红薯/玉米/南瓜）；睡前 3 小时进食完毕
- **加餐（可选）**：无糖酸奶 100~150g、原味坚果 10~15g（约一小把）、低糖水果 1 个（苹果/蓝莓/柚子）
- 忌：含糖饮料、酒精（1g 酒精 7kcal 且优先供能阻断脂肪分解）、油炸、"健康零食"（果蔬干、风味酸奶）

### 增肌版（按 TDEE + 200~300 执行）

- **早**：鸡蛋 2~3 个 + 全脂奶 300ml + 面包/包子/燕麦 + 香蕉 1 根
- **中**：主食 1.5~2 拳 + 肉一掌半（鸡腿肉/牛肉/鱼）+ 蔬菜两拳 + 可加汤
- **练后**：碳水 + 快蛋白（香蕉 + 蛋白粉，或牛奶 + 面包）
- **晚**：正常主食一拳半 + 肉/蛋/鱼 + 蔬菜；睡前可选酪蛋白类：无糖酸奶/牛奶一杯
- 增肌吃不下怎么办：液体热量（牛奶、奶昔、果汁少量）、坚果与牛油果密度高、三餐 + 2~3 次加餐

### 烹饪与外食原则

蒸、煮、炖、烤、快炒（少油） > 煎 > 炸；每日烹调油 25~30g；调味减钠；火锅选清汤锅底 + 蛋白 + 蔬菜，蘸料用醋/海鲜酱替换麻酱。

## 体重控制学要点

- **能量平衡是唯一底层逻辑**：所有方法（轻断食、生酮、代餐）起效都是因为制造了缺口；选用户能长期执行的形式即可，不迷信某种"神奇窗口"。
- **体重波动解读**：单日 ±1~2kg 多为水分（钠摄入、碳水糖原、生理周期、便秘）；看每周 3~4 次晨起空腹（排便后）称重的均值。
- **平台期处理（体重 2~3 周无变化）**：
  1. 先核查执行：饮食记录是否走样、步数是否下滑、睡眠是否变差
  2. 加日常活动：日步数 +2000
  3. 再动热量：下调或上调 100~200 kcal（长期大缺口身体会降代谢，有时"多吃一点"反而突破）
  4. 或安排 1~2 周"维持期"（diet break）：热量回到 TDEE，给心理与激素喘息
- **减重速度红线**：持续 >1% 体重/周 → 上调热量 100~200；伴随乏力、掉发、月经紊乱 → 立即上调并观察。
- **反弹预防（减脂结束）**：用 4~8 周把热量逐步加回 TDEE（每周 +100~150），同时保持力量训练与步数；减脂期养成的习惯不要在结束当天全丢。
- **行为学技巧**：环境设计（家里不囤零食）、固定进餐时间、餐前一杯水、用小盘子、每周允许 1 次自由餐（不是欺骗日暴食）。

## 补给品（运动营养补充剂）

定位先讲清楚：**锦上添花，不替代吃饭、训练、睡眠**。收益排序：蛋白粉 ≈ 肌酸 > 咖啡因 > 维D/鱼油 > 其他。

### 蛋白粉

- 用途：便捷补足蛋白缺口（不是必需品，肉蛋奶吃够可以不用）
- 类型：乳清浓缩蛋白（性价比首选）、乳清分离蛋白（乳糖不耐/易胀气选这个）、水解乳清（吸收快、贵）、大豆/豌豆蛋白（素食）
- 用法：20~40g/次，练后或任意蛋白不足的时段；用水/牛奶冲，不要用开水
- 换算：1 勺（约 30g）蛋白粉 ≈ 24g 蛋白 ≈ 4~5 个鸡蛋白；等价食物：鸡胸肉 100g ≈ 22~25g 蛋白

### 肌酸

- 首选一水肌酸（Creatine Monohydrate），研究最充分、最便宜的增力补剂
- 用法：每天 3~5g，长期每天吃（训练日与休息日都吃），无需冲击期（可选 20g/天 ×5~7 天快速饱和，肠胃弱者跳过）；时间任意，随餐或随训练均可
- 预期：提升力量与训练容量 → 间接多增肌；初期体重 +1~2kg 是肌肉储水，属正常现象
- 安全性：健康人群长期使用安全性良好；**有肾病史或服用影响肾功能药物者先咨询医生**；未满 18 岁不建议使用
- 选购：认准纯一水肌酸，无需买"进阶配方"

### 其他（简述即可，不主动推销）

- 咖啡因：练前 30~60min 服 3~6 mg/kg 提升表现；下午 4 点后避免（影响睡眠）
- 维生素 D：日晒不足者 1000~2000 IU/天
- 鱼油：不爱吃鱼者 1~2g EPA+DHA/天
- 电解质：大量出汗（>1h 运动或夏季徒步）时补充
- **明确不推荐**：左旋肉碱"减脂"、酵素、暴汗服、利尿类减脂药、任何三无减脂产品——遇到用户询问要劝退
- 特殊人群（孕期、哺乳期、未成年人、慢性病用药者）：任何补充剂先问医生
