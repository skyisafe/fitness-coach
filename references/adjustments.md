# 动态调整协议（回访调整）

定位：计划交付后的持续调整流程。用户带着执行反馈回来时**不重新采集、不重铺全表**——先分类反馈，再按层级调整，每次调整都写明依据与下次复核点。

---

## 第一步：反馈分类（四类）

| 反馈类型 | 典型原话 | 处理重点 |
|---|---|---|
| 执行反馈 | 「深蹲 40kg 轻松做满 12 次」「跑步 7.5 太累/太轻松」 | 重量、坡度、配速校准（见下文执行细则） |
| 进度数据 | 「两周了体重没掉」「腰围小了 2cm」「力量涨了」 | 4 周决策窗口规则，不动结构 |
| 条件变化 | 「下周出差」「健身房关门了」「只能练 2 天」「哑铃最大 10kg」 | L2 结构调整（动作替换 / 排期重构） |
| 疼痛与伤病 | 「膝盖疼」「腰不舒服」「感冒了」 | 安全红线优先：停 / 换 / 降 / 就医 |

## 第二步：按层级调整（三级，能用低层级解决就不升级）

- **L1 参数调整**（最常用，不动结构）：重量、次数、组数、休息、坡度、配速、时长、热量、步数——依据双重渐进法、心率校准、4 周窗口规则，每次只动 1~2 个变量
- **L2 结构调整**：动作替换（伤病 / 器材受限，用 `venues.md` 的替代与降阶版）、排期重构（可用天数变化 → 换分化模板）、频率调整
- **L3 目标重估**：连续两个决策窗口不达标 → 重算 TDEE 与热量目标、重估达成时间，与用户对齐预期后再调

---

## 力量训练调整细则（依据训练日志）

- 用户汇报「某重量能标准做 N 次」→ 换算处理：
  - 轻松打满 12 次 → 加重量（哑铃 +2kg，杠铃 / 器械 +2.5~5kg），次数回落到 8 重爬（双重渐进法）
  - 余力 3~4 次（RPE 7）→ 维持，该重量即为正式起点
  - 加重后做不满 8 次 → 退回上一重量多停 1 周
- 同一动作连续 2 次训练没进步 → 逐项检查、每次只调一个：睡眠与蛋白质够吗 → 组间休息够吗（复合 2~3min）→ 容量是否过高（单次 ≤20 组）→ 该肌群频率是否不足
- 用户没记日志 → 先按体感（轻松 / 刚好 / 力竭）调，并要求从下次训练起记录

## 有氧调整细则（跑步机 / 跑步 / 单车）

- 汇报「配速 + 跑后心率 + 能否说完整句子」→ 对照区间重开处方：低于区间下限 → 速度 +0.5 km/h 或坡度 +1%；超上限或说不出句子 → 速度 −0.5 km/h
- 心率区间用 Tanaka：最大心率 = 208−0.7×年龄；中等强度 = 64%~76% HRmax 或 40%~59% HRR；「Zone 2」≈60%~70% HRmax（行业俗称）
- 同心率下配速提升 ≈1 km/h → 过渡到进阶结构：先加时长（+5~10min/周），再加间歇（30s 快 + 90s 慢走 ×6~8，每周 ≤1 次）
- 膝盖不适 / 状态差 → 切坡走平替（10~12% + 5.0~5.5 km/h），不硬撑配速

## 进度数据调整（4 周决策窗口，不对单日波动反应）

| 情况 | 判定条件 | 调整（先动一个变量） |
|---|---|---|
| 减脂不掉 | 4 周体重均值不变且执行合格 | 热量 −100~200 或步数 +2000 |
| 减脂不掉但执行不合格 | 记录/步数没完成 | 先解决执行，不动热量 |
| 减脂过快 | >1 kg/周（>100kg 按 1%/周），持续 2 周 | 热量 +100~200（保肌肉） |
| 增肌不涨 | 4 周体重均值不涨 | 热量 +150~200 |
| 增肌过快 | 体重涨且腰围同步涨 | 热量回调 100~150 |

体重均值 = 每周称 3~4 次取平均；腰围（脐水平）是内脏脂肪风险的第一指标，优先于体重。女性黄体期水钠潴留可让体重上涨 0.3~2kg，**用 7 日均值或同相位对比**，不据此下调热量。

## 条件变化与特殊状态调整

- **可用天数变化** → 换分化模板（5→3 天：合并为主干全身；3→2 天：全身 A/B），频次下降时每次训练保留全部复合动作
- **器材变化** → 按 `venues.md` 同模式替换（清单外器材不假设存在）
- **出差 / 旅行** → 给无器材 20~30min 最低有效剂量课表（酒店房间可完成：俯卧撑 / 分腿蹲 / 划船替代 / 核心）+ 日步数目标
- **单次时间缩短** → 保留复合动作、砍孤立动作，用超级组提密度；不低于 20min
- **停训回归** → ≤2 周从上次重量 80~90% 恢复；2~12 周从四周计划 W1 重来；>12 周按零基础重排 W1（容量 50%~60%），先重建动作模式
- **月经期 / 经前不适** → 症状导向：痛经、头痛、疲劳、睡眠差时当天降一档（减 1~2 组或降 10%~20% 负荷）；症状轻照常训练。不按卵泡期/黄体期硬性分相排课（证据有限）
- **时差 / 夜班** → 睡眠优先：抵达后前 1~2 天只做低强度 + 多晒太阳，不当天上强度；下夜班先补觉 4~6 小时，醒后练、强度降一档；睡眠不足不冲大重量与 HIIT（经验建议，无权威定量指南）
- **高温 / 感冒** → 发烧停训；轻症减半强度，好转后从 80% 重量恢复；高温高湿天降强度、补电解质

## 疼痛与伤病调整（安全红线优先）

- 尖锐 / 刺痛 / 关节痛 → 立即停该动作，换无痛动作（降阶或换模式）；48~72 小时不缓解建议就医
- 肌肉酸痛（DOMS）→ 正常现象，可训练但降强度；**DOMS 与损伤性疼痛的区分标准见 `technique.md` §六**（DOMS 24~72h 达峰、双侧对称、活动后减轻；损伤性疼痛单侧、定位明确、越动越疼）
- 感冒发烧 → 发烧停训；轻症减半强度，好转后从 80% 重量恢复
- 胸痛、心悸、严重头晕、晕厥等红线症状 → 直接建议就医，不给训练调整
- 关节肿胀发热、交锁、打软腿、麻木无力、外伤后不能负重 → 直接就医，不留在训练层处理

## 调整输出格式（对比表 + 全量课表）

```
## 本周调整（第 N 周）
| 项目 | 原计划 | 调整为 | 依据 |
|---|---|---|---|
| 上斜哑铃卧推 | 单边 10kg ×4×8~12 | 单边 12kg ×4×8~12 | 上周 12 次打满、余力足 |
（未列出的动作与安排保持不变）
## 下次反馈点
下次训练后回报：新重量的组次完成情况 / 跑后心率与配速体感
```

- 对比表只写变化项 + 一句「未列出保持不变」；对比表之后必须随附调整后的**全量周课表**（用户要求：每次调整完都要交付一张可直接照练的完整课表，不得只给变化项收尾），并重申本阶段心率区间 / 热量 / 步数硬指标
- 复核节奏：力量与有氧参数每次训练后可调；热量、步数、目标类按 4 周窗口调
- 免责声明与计划交付时一致：一般性建议，不构成医疗建议

## 训练日志模板（首次交付计划时随计划给出，闭环起点）

| 日期 | 动作 | 重量×次数×组数 | 体感（轻松/刚好/力竭） | 有氧（方式·坡度·配速·时长·跑后心率） |
|---|---|---|---|---|
| 9/10 | 上斜哑铃卧推 | 10kg×10×3 | 刚好 | 跑步机 1%·7.5·30min·135 |

用户开始按模板回报 → 进入动态调整循环。
